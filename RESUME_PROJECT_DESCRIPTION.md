### Project Title
**SAP HRFlow — SAP HCM-Inspired HRIS Simulation** (2026)

---

### Bullet Points for Resume / CV:
- Developed a responsive HRIS portfolio application simulating employee master data, organizational management, personnel actions, time management, and employee self-service workflows.
- Designed SAP HCM-oriented HR process flows for hiring, promotion, transfer, leave quotas, probation confirmation, and employee separation using fictional demonstration data.
- Implemented role-based HR Admin and Employee demo interfaces with client-side LocalStorage workflow persistence.
- Built using React, TypeScript, Vite, Tailwind CSS, and Recharts, with automated CSV reporting across 10 HR operational domains.
- Prepared and configured the application for GitHub repository management and zero-downtime Vercel single-page application deployment.

---

### Short Summary (LinkedIn / Portfolio Bio):
> **SAP HRFlow** is an interactive, enterprise-grade HRIS simulation inspired by SAP HCM architecture, developed by Nancy F (MBA — HR & Systems). The system models end-to-end employee lifecycle workflows—from Infotype-based master records and organizational hierarchy trees (O-C-S-P) to PA40 personnel action simulations, attendance tracking, and employee self-service governance. Built with React, TypeScript, and Tailwind CSS.
